# Candy Carnage: The Game

The storefront game for candycarnage.net. Hosted on GitHub Pages and shown on the Big Cartel home page.

- `index.html` - the whole game (art and code)
- `t1.mp3` - `t8.mp3` - Paranormal PS1 soundtrack (licensed, royalty free)
- `t9.mp3` - Bramblebrush Symphony (title screen)
